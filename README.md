# win-panel · Windows 本地操作面板

浏览器按钮面板，覆盖常用 Windows 操作：定时关机/重启、电源、快捷启动、系统维护。
**零依赖**，Python 3 标准库；只监听 `127.0.0.1:8830`。

## 启动

双击 `start.bat`（自动打开浏览器），或：

```bat
python app.py --no-browser
```

访问 http://127.0.0.1:8830/ ，Ctrl+C 停止服务。

## 功能

| 分区 | 操作 |
|------|------|
| 定时关机/重启 | 15/30/45/60/90/120 分钟预设、自定义 1–1440 分钟、实时倒计时、取消计划（新计划顶替旧计划） |
| 电源 | 立即关机 / 重启 / 注销（二次确认）、锁定、休眠、睡眠 |
| 快捷启动 | 任务管理器、设置、控制面板、此电脑、下载、文档、cmd、PowerShell、记事本、计算器、截图、远程桌面 |
| 系统维护 | 显示桌面（最小化全部窗口）、清空剪贴板、清空回收站 |

## 安全设计

- 只绑定 loopback，局域网/外网不可达；
- **三层防跨站驱动**（浏览器里任意恶网页都不能借它关机/清空回收站）：
  1. Host 白名单：只接受主机名为 `127.0.0.1`/`localhost` 的请求（挡 DNS rebinding）；
  2. POST 只接受 `Content-Type: application/json`（text/plain、HTML 表单等浏览器“简单请求”一律 415，跨域页面无法不发预检就驱动操作）；
  3. 每进程随机 CSRF 令牌：页面先同源 GET `/api/token`，POST 必须携带且常量时间比较；
- 所有操作在服务端**白名单**内（System32 绝对路径的固定 argv / 固定 Win32 API），
  网页无法传任意命令，无 shell 注入面；
- 请求体上限 64 KB、socket 10 s 超时；分钟数服务端强制校验 1–1440 整数；
- 关机/重启/注销必须两步确认；
- 响应头 `Cache-Control: no-store`，异常只记服务端日志、不外泄路径/堆栈。

## 测试

```bat
python -m unittest -v tests.test_app
```

59 个用例：dispatch 全注入替身（不会触发真实关机），HTTP 层覆盖令牌/Host/Content-Type/请求体形状等跨站防御。

## 说明

- Windows 系统只允许一个关机计划；用命令行（`shutdown /s /t ...`）设置的计划，
  本面板无法显示倒计时，但面板的「取消」同样能取消它。
- 命令行取消计划：`shutdown /a`。
